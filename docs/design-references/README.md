# Design references

Visual references chosen by Ali (SnowUI-style web dashboards). They show the **style** to follow; `../design-language.md` turns it into exact rules and wins if anything differs.

| File | What to take from it |
|---|---|
| `01-overview-light.jpg` | Main reference: white grouped sidebar, breadcrumb top bar, bold KPI cards (accent and charcoal gradients), white rounded cards on a soft gray page, table with rounded striped rows and pastel status pills |
| `02-overview-dark.jpg` | Dark theme of the same layout |
| `03-overview-right-panel-light.jpg` | Right-hand panel (notifications, activity) and soft pastel summary tiles |
| `04-overview-right-panel-dark.jpg` | Dark theme of the right-panel layout |
| `05-cards-and-charts.png` | Card spacing, soft tiles, chart style (charts only where real data exists) |
| `06-color-system.png` | The idea of a small token-based palette with light and dark themes |

These are third-party designs used only as internal visual references in this private repository. Do not copy their logo, illustrations, avatars, sample names, or data into the app. If we ever want to use the actual kit files or components, check the kit's license first.
