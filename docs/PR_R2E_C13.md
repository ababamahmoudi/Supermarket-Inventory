# R2e C13 — One operational timesheet language

Timesheets → choose a branch. In English the department title is English only; switch the app to Persian and it uses Persian only (English fallback if not configured). Day and Week hours use compact H:MM without wrapping. Previous/next day arrows mirror in Persian. Print retains both languages and the existing paper composition.

Proof: compact-minute formatting and retained bilingual paper wording unit tests; real desktop/phone browser checks for selected-language titles, hours and mirrored arrow icons.
