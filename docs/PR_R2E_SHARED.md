# R2e shared fixes review

## B1 — Table alignment

Sortable numeric captions keep their label on the values' logical end edge. The sort indicator sits before an end-aligned caption, so choosing a sort never moves the caption away from the value edge. Every shared numeric header uses zero inline button padding and the same alignment as its cells. Shared tables retain 12 px inner cell padding (24 px between columns), vertically centred row values, and baseline-aligned headers. Receiving quantity/cost/total and invoice batch approval tables use the same logical alignment and spacing. The batch header is sticky with a solid surface and a hairline divider; its first row retains normal top padding.

Test path: sign in as Manager, open Products and click Price twice, then Product Code. Check English and Persian. Open Labels, Received, Returns, Suppliers, Payables and Dashboard; numeric headings end on the values' edge. Import the fictional approval reading, confirm and post it, open Approvals → Approve all, and scroll the review table. The header remains opaque and aligned.

Browser proof measures actual text ranges at 1440 px in English and Persian, including dashboard approvals/recent invoices, posted invoice lines, batch approvals and the Price updates list generated by a real approval. It fails above 1 px difference rather than comparing cell boxes alone.

## B2 — Reversible quick filters

Products, Labels, Suppliers and Lookup use the same shared `FilterChip`: click, Space or Enter toggles `aria-pressed`; selected chips have accent tint/text and a check. The check's space is reserved in both states, preventing a selection from moving neighbouring controls. Received's Today/This week/This month date presets use the same selected chip and clicking the selected preset again clears the date range. Category choices remain single-choice controls.

## B3 — Visible Off switches

An Off switch keeps a neutral segmented-track fill, a hairline border and a white thumb. On keeps the existing accent fill. The existing 44 × 26 px track and thumb travel remain unchanged in English/Persian and both themes. Open Edit product → Date tracking or a Settings switch and toggle it twice; the whole track stays visible while Off.

## B4 — Modal feedback

While any modal is open, recent-action feedback is a quiet status in its footer, beside the actions, with the genuine Undo. No dark toast enters a dialog or covers its rows. The page toast stays deferred until the last modal closes, then appears at the page's bottom-end corner above any sticky page action bar. Its remaining eight-second budget pauses during the modal, preserving the actual Undo opportunity rather than expiring while hidden. It remains personal to the actor and uses the existing protected Undo command.
