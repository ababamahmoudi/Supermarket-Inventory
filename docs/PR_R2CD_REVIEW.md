## Start the app on Ubuntu

Use Node 22.22.2 or a newer Node 22 release. In your existing checkout:

```bash
git switch feat/prototype-r2-receiving
git pull --ff-only origin feat/prototype-r2-receiving
cd prototype
node --version
npm ci
npm run build
npm run preview
```

Open `http://localhost:5174`. A phone on the same Wi-Fi can use the displayed Network address; see `docs/phone-demo-hosting.md` for Ubuntu/VM/firewall details. Stop preview with Ctrl+C, rebuild and restart preview after pulling another update. Each browser/origin has its own local records. Normal upgrades preserve saved records; do not reset a browser containing records you need. An isolated browser profile gives you a fresh fictional demo for rehearsal.

Fresh demo accounts use password `demo1234`: `manager`, `owner`, `rh-supervisor`, `ny-floor`, `wh-floor`, and `cashier`. Privileged accounts also choose **Use simulated passkey**. The configured branch labels appear in the location selector. Repeat visual review at 1440, 1000 and 390 pixels, in English/Persian and both themes.

## Defaults and limits

- Concrete-branch Lookup behavior in 7.3 is the requested default for Ali to confirm. All locations retains separate public branch detail rows.
- Creation records one received product/line per form. Whole-unit returns use integers; lb allows at most three decimals so the full quantity can be picked up under existing rules. Unit costs retain four decimals. Exact request retries are idempotent; a separate intentional request can describe the same goods.
- Staff are branch records with optional app-login links. Past days stay editable by the four permitted roles with History; payroll week view and CSV are included. On shift counts include prior unclosed days until a person records Out.
- Waiting-pickup return credits are informational until the established pickup operation deducts once. A receipt in a different currency, an ambiguous source or an invalid cost requires Manager review. Historical currency must resolve from consistent retained invoice/posting evidence, including manual invoices; missing or conflicting evidence blocks creation. New returns retain that source cost/currency despite later receipts. A later company-currency change preserves the original preview denomination and blocks the new return's pickup/correction/monetary credit writes until it matches. The app does not invent foreign exchange or silently relabel receipt money.
- Derived subtotal does not invent unknown paper tax or a person's acknowledgment. The configurable handwritten-delivery window defaults to 06:00–20:00; branch opening hours remain separate configuration.
- The exact private supplier-disappearance sequence was not reproduced. The fictional lifecycle proof retained suppliers; reproducible failed-read empty states, remembered-filter issues and the late-post navigation race were fixed and are documented separately.
- This remains the browser prototype with protected canonical IndexedDB operations, not a new production HTTP backend or cross-device service. AI reading and privileged authentication remain simulated. No deployment or paid resources were created.
- Phone checks use browser emulation. Print proof covers browser print media and an actual Chromium A4 PDF; physical iPhone/Safari/printer output still requires Ali's device review.
