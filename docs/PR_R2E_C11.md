# R2e C11 — Lookup quick filters

Lookup → choose a location. On offer, Expiring soon, Arrived today and Price changed recently combine with Taxable, Not approved here yet and category filters. Click a selected chip to remove it; Clear filters removes all choices. Choices remain scoped to the same person/company/location.

An active tracked date within the product's configured reminder window adds an amber Expiring soon badge beside offer facts in both the result row and product card. Stopped tracking does not create a reminder badge. The existing Dates section remains the detailed record.

The protected selector emits public booleans only, after current company/location authorization. It does not expose private receipt, decision, staff or cost evidence. Price changed recently uses the existing label settings window (default three days); future/cancelled decisions do not count. Aggregate Lookup uses facts from authorized locations without selecting one for writes.

Proof includes combined filter/persistence/clear browser actions, expiry badges on actual rendered rows/card, current/foreign/unassigned evidence, historic/future exclusions and a public-field allowlist assertion.
