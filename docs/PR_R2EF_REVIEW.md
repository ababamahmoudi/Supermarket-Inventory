Work remains on `feat/prototype-r2-receiving`, [PR #29](https://github.com/ababamahmoudi/Supermarket-Inventory/pull/29). R2e was completed/pushed before the R2f design work. No merge or force-push is included. Private review screenshots/recordings and invoice data remain outside the repository; the approved fictional design PNGs and supplied Klead assets are retained exactly.

## Run on Ubuntu

Use Node 22.22.2 or a later Node 22 release, then in the existing repository:

```bash
git switch feat/prototype-r2-receiving
git pull --ff-only
cd prototype
npm ci
npm run build
npm run preview
```

Open `http://localhost:5174`. Sign in with username `manager` and password `demo1234`, then complete the simulated passkey step. Choose North York. Stop preview with Ctrl+C before rebuilding; restart preview after every new build. Keep an existing saved store to check migration preservation. Use a separate browser profile for a fresh fictional demo; do not clear an existing store to upgrade it. The app stores this prototype's data in the current browser.

## Screenshot differences and explicit defaults

- The approved Dashboard phone PNG places This week immediately after the tiles and before Approvals; that order overrides the prose's after-chart sentence. Reminder window is truthful for configurable product reminder horizons instead of a fabricated universal seven-day limit.
- Lookup phone actions sit below product metadata and Next expiry is omitted from the compact location row, matching the PNGs. Needed AI-category filtering stays in a compact More filters disclosure, with a visible active summary and Clear.
- Branch requests retain an optional compact Pack disclosure when the existing non-catalog workflow requires an unambiguous pack; this preserves the real required input.
- Approved FA weight price/size labels use the shared localized mass contract; other screens keep their established Latin-unit default. Stored units, quantities and Decimal prices are unchanged.
- Exact narrow composition exceptions are registered with reasons; numeric/control budgets remain 1.5 px centres/edges and 2 px heights, and shifted negative controls must fail. Timesheet masonry cards have independent compact headers and natural height; only genuinely neighbouring paired cards stretch.
- Live current-day hours are display-only. Missing Out remains zero in completed payroll/week/CSV; the UI never invents an Out. Past/future missing clocks keep their actual semantics.
- Package barcodes accept valid unique GTIN8/12/13/14; generated in-store codes use the configured prefix. Container price fee defaults to $0.49, container cost to $0.00. Only actual branch-approved parent prices authorize derived branch selling prices. New package date tracking starts Off; no expiry is invented.
- Package New size uses the same actual active-Sale/staged Keep/Change/End basis as Save. The regular price card remains regular; no query creates business evidence. All-location cost decisions create separately authorized branch reviews, retaining each branch’s real prior cost/manual provenance.
- Unknown return credit is unknown, never guessed zero. Credit remains in the retained source currency and uses existing financial permissions; there is no invented FX.
- The maker identity is secondary/configurable. Saved explicit Off, null, custom values and existing records are preserved; supplied asset bytes are unchanged.
